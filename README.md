# SNS 댓글 모니터링 및 업무 자동화

Python, Make, Zapier를 활용한 SNS 댓글 데이터 처리 및 검토 업무 자동화 프로젝트입니다.

## 1. 프로젝트 개요

SNS 댓글을 담당자가 수동으로 확인하고 분류하는 반복 업무를 줄이기 위해 데이터 전처리부터 주의댓글 분류, 저장, 검토 요청까지 연결하는 자동화 시스템을 구현했습니다.

- 프로젝트 유형: 개인 프로젝트 (교육과정 종합 실습)
- 구현 방식: 강의자료를 참고하여 직접 설정 및 구현
- 기술 스택: Python, pandas, Make, Zapier, Gmail, Google Sheets

## 2. 시스템 아키텍처

```text
SNS 댓글 CSV 데이터
        ↓
Python (pandas)
결측치·중복 제거 및 데이터 정제
        ↓
Gmail SMTP
전처리 CSV 파일 전송
        ↓
Make
메일 감지 → CSV 파싱 → 조건 분류
        ↓
Google Sheets
전체댓글 및 주의댓글 저장
        ↓
Make / Zapier
일일 요약 · 정기 검토 요청 · 미확인 재조회
```

## 3. 주요 구현 기능

### Python 데이터 전처리
- 댓글 ID 및 댓글 내용 결측치 제거
- 중복 댓글 제거
- 정규표현식을 활용한 HTML 태그·공백 정리
- 좋아요 및 답글 수 정수형 변환
- 혼합 날짜 형식 변환 및 CSV 저장

### Make 자동화
- Gmail에서 특정 제목의 이메일 감지
- 첨부된 CSV 파일 파싱
- Google Sheets에 전체댓글 저장
- 키워드 및 좋아요 수 기준 주의댓글 분류
- 주의댓글 별도 저장 및 일일 요약 이메일 발송

### Zapier 자동화
- 매일 오후 4시 검토 요청 실행
- Google Sheets에서 미확인 댓글 검색
- 담당자 검토 요청 이메일 발송
- 1일 후 미확인 댓글 재조회 및 조건부 리마인드 설계

## 4. 프로젝트 결과

| 항목 | 결과 |
|---|---|
| 원본 댓글 | 200건 |
| 전처리 완료 | 175건 |
| 주의댓글 | 50건 |
| 일일 요약 이메일 | 발송 확인 |
| 검토 요청 이메일 | 발송 확인 |

※ 주의댓글 50건은 테스트 실행에서 발송된 이메일의 집계 결과입니다.

## 5. 문제 해결 및 기술적 학습

- 결측치와 중복 데이터가 자동화 과정에 미치는 영향을 고려하여 전처리 절차 구성
- 혼합된 날짜 형식을 처리하기 위해 pandas의 날짜 변환 옵션 활용
- CSV 파일의 한글 깨짐을 방지하기 위해 UTF-8 BOM 인코딩 적용
- Make의 Router 및 Aggregator를 활용한 조건 분기와 집계 처리
- Zapier에서 시간 지연 후 처리상태를 재조회하도록 워크플로우 구성

## 6. 한계 및 향후 개선

- 현재 주의댓글 분류는 키워드와 좋아요 수에 기반한 규칙 기반 방식입니다.
- 문맥에 따른 오분류를 줄이기 위해 향후 LLM 기반 분류 기능을 검토할 수 있습니다.
- 중복 적재 방지 및 오류 발생 시 재시도·알림 기능을 추가할 계획입니다.
- 현재 Python 데이터 전처리는 수동 실행 방식이며, 추후 전체 자동화로 확장할 수 있습니다.
