# SNS 댓글 모니터링 자동화

Python, Make, Zapier를 활용한 SNS 댓글 관리 업무 자동화 프로젝트입니다.

## 프로젝트 개요
댓글 데이터의 전처리부터 주의댓글 분류, Google Sheets 저장, 이메일 검토 요청까지 연결하는 자동화 워크플로우를 구현했습니다.

## 사용 기술
- Python, pandas
- Make, Zapier
- Google Sheets, Gmail

## 구현 기능
- 댓글 데이터 결측치 및 중복 제거
- 텍스트, 숫자, 날짜 형식 정제
- 키워드 및 좋아요 수 기반 주의댓글 분류
- 전체댓글 및 주의댓글 자동 저장
- 일일 요약 이메일 발송
- 검토 요청 및 미확인 댓글 재조회 워크플로우

## 프로젝트 결과
- 원본 댓글 200건 중 175건 전처리
- 주의댓글 50건 분류 및 요약 이메일 발송 확인

## 구현 방식
강의자료를 참고하여 Python 전처리 및 Make·Zapier 워크플로우를 직접 설정하고 구현했습니다.
